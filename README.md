# NurseDashboard
# NovaCare EHR — AI Bed Placement System

**[▶ Live Demo](https://Nbhandari3.github.io/NurseDashboard)**

An AI-powered Emergency Department bed management system built to reduce 
nurse cognitive burden and improve patient flow.

## Features
- 🤖 6-factor AI bed assignment engine (specialty, nurse load, isolation, LOS)
- 🧠 ESI triage priority suggestion from live vitals
- 📋 One-click automated shift handoff report
- ⬇ AI step-down suggestions to free critical beds proactively
- 🚑 EMS incoming bed reservation system
- 🔄 Patient transfer tracking (beds held during procedures)
- 👑 Charge nurse control panel with full override + audit log
- 🔐 Role-based access (Bedside RN vs Charge Nurse)

## Tech Stack
Pure HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

## How to Run Locally
Just open `index.html` in any browser.
